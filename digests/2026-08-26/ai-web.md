- **发布日期**：2024-12-12（初版），2026-08-24（重大更新）
- **核心观点**：Clio 已正式更名为 **Anthropic Insights**，系统功能升级，同时更新消费者条款和隐私政策。该工具在严格保护用户隐私的前提下，分析真实世界的 AI 使用模式。

#### 【关键】劳动力再培训项目效果元分析

- **发布日期**：2026-08-12
- **核心观点**：Anthropic 联合独立研究者 David Roodman 发布系统性审查，分析 56 项美国随机对照研究及欧洲实验数据。结果显示：
  - 平均每位参训者就业率提升 2-3 个百分点
  - 年收入增加约 1,000 美元
  - 项目成本约 13,000 美元/人
  - 政府可通过税收和减少福利支出回收约一半支出
- **政策含义**：传统再培训政策的实际效果"积极但有限"，Anthropic 在为其政策框架提供实证依据的同时，也隐含了"仅靠再培训不足够"的结论。
- **链接**：[Reviewing the evidence on worker retraining programs](https://www.anthropic.com/research/reviewing-the-evidence-on-worker-retraining-programs)

#### 81,000 用户经济调查

- **发布日期**：2026-04-22
- **核心观点**：Anthropic 调查了 81,000 名 Claude 用户的关键发现：
  - **暴露于 AI 程度更高的职业**，对岗位替代的担忧更强烈
  - 高/低收入群体的生产率提升最大（主要来自范围扩展）
  - 感到速度提升最大的用户，对岗位替代的担忧也最高
- **洞察**：用户对 AI 的态度呈现**复杂性**——既感到生产力提升，又担忧失业，且这种矛盾感在高暴露群体中更为突出。
- **链接**：[What 81,000 people told us about the economics of AI](https://www.anthropic.com/research/81k-economics)

#### Claude Code 使用实践研究

- **发布日期**：2026-06-16
- **核心观点**：基于 2025年10月至2026年4月的约 400,000 个 Claude Code 会话分析：
  - 用户负责**规划决策**，Claude 负责**执行决策**
  - 用户领域专长越强，Claude 完成的工作量越大
  - 所有主要职业的代码任务成功率与软件工程师相当
  - 7 个月内调试会话占比下降近一半
  - 任务价值平均提升约 **25%**
- **关键洞察**：AI 编码助手正在从"辅助工具"演变为"半自主执行者"，任务性质正向端到端 agentic 使用转变。
- **链接**：[How Claude Code is used in practice](https://www.anthropic.com/research/claude-code-expertise)
